# DryRunAI Service 03: Review Builder

The Review Builder collects, normalizes, validates, organizes, and exports product reviews. It does not perform AI tasks, sentiment analysis, spam detection, or trust scoring. Original review text is preserved.

## Folder Structure

```text
03_review_builder/
  review_builder/
    collectors/    Plugin-based source collectors.
    processors/    Review normalization and product linking.
    validators/    Required field, rating, language, and duplicate validation.
    exporters/     Versioned reviews, quarantine, metadata, and report exports.
    reports/       Report payload builders.
    config/        Service defaults.
  logs/            Service-local placeholder. Runtime logs default to datasets/processed/logs.
  tests/           Unit tests.
  docs/            Additional service documentation.
  output/          Service-local placeholder.
```

## Inputs

The service reads `products.csv` generated by Service 01 and uses the Product IDs from that catalog. It never modifies `products.csv`.

Review input can be CSV, JSON, JSONL, or a directory of those files.

## Outputs

Versioned outputs are written under `datasets/reviews/`:

```text
datasets/reviews/versions/reviews_v1/processed/reviews.csv
datasets/reviews/processed/reviews_v1/reviews.csv
datasets/reviews/quarantine/reviews_v1/rejected_reviews.csv
datasets/reviews/quarantine/reviews_v1/duplicate_reviews.csv
datasets/reviews/reports/reviews_v1/review_summary.json
datasets/reviews/reports/reviews_v1/validation_report.json
datasets/reviews/reports/reviews_v1/duplicate_report.json
datasets/reviews/reports/reviews_v1/statistics.json
datasets/reviews/metadata/reviews_v1/source_metadata.json
```

Versions are never overwritten.

## Collector Interface

Collectors subclass `BaseReviewCollector`, set `source_name`, and implement:

```python
collect(input_path: Path) -> list[RawReview]
```

Register a collector in `build_registry()` inside `review_builder/pipeline.py`.

## Product Linking

Reviews are linked to Product IDs using, in order:

1. Existing DryRunAI `product_id` in the review row.
2. Source plus source product ID, such as Amazon ASIN or Zappos SKU.
3. Source URL when it matches `products.csv`.

Rows that cannot link to a product are rejected and written to quarantine.

## Run

From the DryRunAI root:

```powershell
$env:PYTHONPATH = ".;03_review_builder"
python -m review_builder --source amazon --reviews "datasets/reviews/raw/amazon_reviews.jsonl" --products "datasets/versions/catalog_v1/products.csv"
```

If `--products` is omitted, the latest `datasets/versions/catalog_v*/products.csv` is used.
